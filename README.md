# 新手小廚房

提供繁體中文簡單料理食譜，適合料理新手、學生與忙碌族群。以共用版型與 AGENTS.md 規則維持可擴充的內容結構。

## 目前內容

首頁提供五張食譜卡片與關鍵字搜尋。

| 料理 | 分類 | 份量 | 備料 | 烹調 | 額外等待 | 預估總時間 |
|---|---|---|---|---|---|---|
| 番茄炒蛋 | 家常菜 | 2 人份 | 8 分鐘 | 12 分鐘 | 0 分鐘 | 20 分鐘 |
| 蒜香炒菇 | 家常菜 | 2 人份 | 8 分鐘 | 10 分鐘 | 0 分鐘 | 18 分鐘 |

| 蒜炒高麗菜 | 家常菜 | 2 人份 | 7 分鐘 | 8 分鐘 | 0 分鐘 | 15 分鐘 |

蛋炒飯以已有熟白飯為前提，不含從生米煮飯的時間；海帶芽豆腐湯使用可直接入湯的乾燥海帶芽。若改用需浸泡的產品，額外計入準備時間。

食譜由 AI 協助整理，尚未實際試作。

## 本機預覽
完整解壓縮專案後，雙擊 index.html，用瀏覽器開啟。不需安裝套件，也不需要執行建置指令。不要只移動 index.html，請保留整個資料夾。

## GitHub Pages 部署
1. 在 GitHub 建立公開 repository，例如 simple-recipes。
2. 上傳本資料夾「裡面」的所有檔案，保留 recipes/ 子資料夾。index.html 應位於 repository 最外層，不要上傳 ZIP 代替原始檔。
3. 在 Settings → Pages，選擇 Deploy from a branch，分支 main，資料夾 / (root)，儲存。
4. 發布完成後，使用 Pages 顯示的網站網址，確認首頁與五篇食譜皆可正常瀏覽。
5. 作業繳交時，提供 repository 網址、網站網址、專案簡介、AGENTS.md 與規則延伸說明。

本專案尚未上傳 GitHub 或部署，公開網址需待部署後補上。

## 如何新增食譜
先閱讀 AGENTS.md 與任一現有食譜，再新增 recipes/英文小寫名稱.html。沿用共用樣式與全部章節，同時在首頁加入名稱、份量與時間一致的卡片。確認連結、手機排版與來源標示。

可提供給 AI 的指令：
> 請遵守 AGENTS.md，新增一道簡單料理食譜，沿用現有版型，補齊全部章節，更新首頁食譜列表。不要重新設計網站，完成後列出修改內容與實際檢查結果。

## 規則如何支持延伸
五篇食譜使用相同章節順序、共用 styles.css 與相對路徑。新增下一篇時，只需依既有結構建立食譜並更新首頁，不需修改網站架構。AGENTS.md 同時規定命名、份量時間一致性、來源標示及檢查流程。

## 關鍵字搜尋
首頁可即時搜尋料理名稱或食材。例如「蛋」找到番茄炒蛋與蛋炒飯，「蒜頭」找到蒜香炒菇與蒜炒高麗菜，「豆腐」找到海帶芽豆腐湯。「番茄 雞蛋」會找出同時符合兩個關鍵字的食譜。空白或清除搜尋會還原全部卡片；無符合結果時會顯示提示。

搜尋使用 search.js 在本機運作，無需 API、後端或額外安裝。新增食譜時，請同步更新首頁卡片的 data-search 食材與名稱，詳細規則見 AGENTS.md 第 12 節。
